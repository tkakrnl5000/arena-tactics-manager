# ⚔️ 6인의 원정대 (Six Expedition: Idle Raid)

6명이서 실시간으로 동시에 모이지 않아도 비동기적으로 즐길 수 있는 **방치형 협동 웹 RPG 게임**입니다.

---

## 🎮 게임 실행 방법
1. `C:\dee` 폴더 안에 있는 **[index.html](file:///C:/dee/index.html)** 파일을 더블 클릭하여 크롬이나 엣지 등 원하는 웹 브라우저로 엽니다.
2. 별도의 Node.js 설치나 복잡한 웹 서버 구동 없이 즉시 실행됩니다!

---

## 🌟 핵심 특징

### 1. 6인 플레이어 역할 분담
* **6개의 영웅 슬롯**이 제공되며, 6명의 친구가 각자 한 명씩 캐릭터를 맡아 육성합니다.
  * **1번**: 바바리안 (탱커)
  * **2번**: 아크메이지 (광역 딜러)
  * **3번**: 성기사 (파티 버퍼)
  * **4번**: 암살자 (치명타 극딜)
  * **5번**: 엘프 궁수 (속사 딜러)
  * **6번**: 대사제 (성자/힐러)
* 각 영웅의 이름 입력란을 클릭하여 **실제 친구들의 닉네임**으로 자유롭게 변경할 수 있습니다.

### 2. 비동기 방치형 육성 & 오프라인 보상
* 게임 창을 켜두면 원정대가 자동으로 던전을 전진하며 사냥합니다.
* 게임 창을 닫아두거나 잠을 자고 와도, 다시 접속할 때 **경과 시간(최대 24시간) 동안 누적된 골드, 에테르 마석, 경험치**가 "방치 보상 팝업"으로 지급됩니다!
* 각 영웅별로 **[⚔️ 던전 사냥] / [⛏️ 마석 채굴] / [📖 수련원]** 중 원하는 방치 임무를 지정할 수 있습니다.

### 3. 세이브 & 6인 비동기 공유 시스템
* **LocalStorage 자동 저장**: 브라우저를 껐다 켜도 직전 상태가 유지됩니다.
* **클라우드 세이브 코드 복사/불러오기**:
  1. 우측 상단 **[💾 저장 / 공유]** 버튼 클릭
  2. **[📋 세이브 코드 복사]**를 누른 뒤, 카카오톡/디스코드 단톡방에 전송
  3. 다른 친구가 코드를 복사하여 **[📥 코드 불러오기]**에 붙여넣으면, 최신 파티 진행 상황을 그대로 이어받아 자기 캐릭터를 육성할 수 있습니다!

### 4. 6인 협동 월드 보스 레이드
* 친구들이 지금 접속해 있지 않아도, 6명의 영웅이 보유한 장비와 스탯이 합산되어 **원정대 총 전투력**으로 거대 월드 보스를 공격합니다.

### 5. Web Audio 효과음 내장
* 외부 오디오 다운로드 없이 브라우저 자체 오디오 신디사이저로 타격음, 레벨업, 승리 효과음이 재생됩니다. (상단 '소리 Off/On' 버튼으로 음소거 가능)
